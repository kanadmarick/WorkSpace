# Flow

## Purpose

This document describes the operational flow of the gameplan from planning to evidence and career outcomes.

## Execution flow

1. Define target role and constraints
2. Select the next roadmap phase
3. Produce a practical deliverable
4. Capture evidence
5. Review trade-offs and failure modes
6. Update the next step based on results

## Career flow

```text
Goal
  -> roadmap phase
  -> technical artifact
  -> evidence capture
  -> interview framing
  -> application and feedback loop
  -> improved targeting
```

## Review flow

A design should pass through this sequence:

- clarify constraints
- compare alternatives
- evaluate failure modes
- validate with metrics
- document final decision

## Decision flow

When making design choices, the flow should be:

- requirement and environment
- risks and assumptions
- implementation choice
- guardrails and observability
- rollback and recovery process

## Evidence flow

```text
Deliverable
  -> artifact
  -> review
  -> recorded note
  -> portfolio evidence
  -> interview answer or case study
```

## Summary

The flow is intentionally simple and repeatable. It keeps the user in a continuous loop of building, validating, and communicating work in a format that supports both portfolio quality and interview performance.
